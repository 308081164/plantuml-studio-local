在本地完成 PlantUML 制图与渲染

面向开发者与架构师的 Windows 桌面应用：内置 Java 与 PlantUML（PicoWeb）离线渲染，集成 DeepSeek 实现自然语言智能生成、项目目录驱动制图与静态架构草图。本页面由与支付回调相同的后端服务在默认端口 8848 提供，用于产品介绍与轻量在线 PlantUML 预览。

核心能力

与开源仓库 README 描述一致的能力摘要

本地 PlantUML 渲染

内置 JRE 与官方 PlantUML JAR，PicoWeb 模式下图表在本地生成 SVG / PNG，无需依赖外网渲染引擎即可完成常规制图。

DeepSeek 智能生成

自然语言描述需求，模型生成 PlantUML 源码；结合本地校验与多轮自动修正，降低语法错误与反复调试成本。

项目目录驱动

选择工程根目录，尊重 .gitignore 与自定义忽略规则；由模型判断是否需要读取仓库上下文，生成更贴近代码结构的图表。

静态架构示意（studio-arch）

针对「与仓库静态 import 结构一致」的模块依赖图，使用独立语法与黑白灰 SVG 渲染，与 PlantUML 路由分流。

暂存与导出

暂存区管理多幅产出；支持导出文件、复制预览 PNG。高级版无限制；免费版对智能生成结果有相应策略（以客户端为准）。

支付与解锁（可选）

自建轻量服务处理订单与支付宝异步通知验签；桌面端可唤起浏览器完成支付后回到客户端拉取解锁状态。

本功能用于公开展示与轻量试用。复杂图或高并发请使用桌面客户端本地渲染以获得更好体验与隐私控制。

点击「渲染预览」生成 SVG
隐私与数据流说明 您提交的源码将由本服务器使用官方算法编码后，向 PlantUML 公共服务（默认 www.plantuml.com，可通过环境变量 PLANTUML_ONLINE_SVG_BASE 覆盖）发起 HTTPS 请求以获取 SVG。请勿包含密钥、令牌或个人敏感数据。图表过大时可能超出在线预览 URL 长度上限，请使用桌面客户端本地渲染。生产站点建议为备案域名配置 HTTPS 反向代理，并将 PUBLIC_BASE_URL 设为该域名根地址以便支付回调一致。

与备案域名一同部署

例如 uml.广厦智汇.com

在反向代理（Nginx / 阿里云 SLB 等）上将 443 转发到本进程监听的 8848，启用 TLS 证书（中文域名需支持 IDN 的证书）。环境变量 PUBLIC_BASE_URL 应设为对外的 https:// 根地址，与支付宝「电脑网站支付」材料中的网站域名保持一致，便于审核与回调验签。
