# 产品付费转化说明（免费版产线 · 可行性）

## 1. 版本与能力分层（已实现方向）

| 维度 | 免费版（未激活默认） | 专业版（有效激活码） |
|------|---------------------|----------------------|
| 手写 PlantUML 并渲染 | 不受限 | 不受限 |
| 智能生成成功后的本条内容 | 源码占位、预览含水印提示、禁用导出/预览复制/加入暂存；可「支付解锁」或升级专业版 | 无上述限制 |
| 支付 0.8 元解锁本条 | 通过自建服务器订单 + `unlockToken` 校验后恢复 | 不需要 |

## 2. 支付宝与「完全不依赖服务器」

严格离线无法完成可验证的支付宝收款；本仓库采用 **自建 Node 服务**（`server/`）完成异步通知验签与令牌发放。详见正文历史说明与 `docs/github-actions-secrets.md`。

## 3. 与本仓库当前实现的关系

- 桌面端（Electron 主进程）持久化激活状态；**未激活即免费版**。  
- 智能生成管道在免费版下写入 **会话锁**（明文 PlantUML 仅驻主进程内存，编辑器展示占位文案）。  
- `server/`：订单、`/api/unlock/verify`、支付宝 `notify` 骨架、**GitHub Actions 发布元数据** `POST /internal/github-release`。  
- CI Secrets 与支付宝键名获取方式见 **`docs/github-actions-secrets.md`**。切勿将服务器 root 密码或应用私钥提交到 git。
