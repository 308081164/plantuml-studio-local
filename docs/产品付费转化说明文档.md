# 产品付费转化说明（免费版产线 · 可行性）

## 1. 版本与能力分层（已实现方向）

| 维度 | 免费版（未激活默认） | 专业版（有效激活码） |
|------|---------------------|----------------------|
| 手写 PlantUML 并渲染 | 不受限 | 不受限 |
| 智能生成成功后的本条内容 | 源码占位、预览含水印提示、禁用导出/预览复制/加入暂存；须经明码激活档位（¥9.9 / ¥39.9 / ¥299 / ¥689）升级为专业版权益 | 无上述限制 |
| 按条单笔付费（¥0.8） | 已停用（平台接入限制）；历史订单接口可能仍存在于 `server/`，桌面端不接此路径 | 不需要 |

## 2. 支付宝与「完全不依赖服务器」

严格离线无法完成可验证的支付宝收款；本仓库采用 **自建 Node 服务**（`server/`）完成异步通知验签与令牌发放。详见正文历史说明与 `docs/github-actions-secrets.md`。

## 3. 与本仓库当前实现的关系

- 桌面端（Electron 主进程）持久化激活状态；**未激活即免费版**。  
- **免费用量**：未激活且未处于月度权益时，每个自然日可使用有限次数（默认 12 次）调用需授权能力；正式激活或月度核销后不受该日限额约束。  
- **月度密钥**：`server/` 提供 `/api/admin/monthly-keys` 登记与 `/api/license/redeem-monthly` 核销（一次性），客户端写入本地 `valid_until`；与 **PlantUML密钥生成器**（`admin-tool-gui`）配合。  
- 智能生成管道在免费版下可写入 **会话锁**（占位文案）；若本次请求已凭免费用量 / 月度 / 正式激活解锁，则不锁定本条展示。  
- `server/`：订单、`/api/unlock/verify`、支付宝 `notify`、自然语言 PlantUML 转换、**GitHub Actions 发布元数据** `POST /internal/github-release`。  
- CI Secrets 与支付宝键名获取方式见 **`docs/github-actions-secrets.md`**。切勿将服务器 root 密码或应用私钥提交到 git。
