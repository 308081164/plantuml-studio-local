# M3 Beta 冒烟清单（PlantUML 本地工作室）

在**干净用户数据**或**备份配置**后，按顺序勾选。版本应 **≥ 2.0.0-beta.2**（或与当前 `package.json` 一致）。

## 1. 启动与渲染

- [ ] 应用启动无报错，状态栏显示已连接 `http://127.0.0.1:*` PicoWeb。
- [ ] 默认示例源码点击「渲染预览」成功（SVG/PNG 切换正常）。
- [ ] 「导出文件…」可下载。

## 2. 剪贴板与 CSP

- [ ] PNG 预览下右键预览区，可复制 PNG 到剪贴板（外贴图验证）。
- [ ] 「加入暂存区」在 PNG/SVG 预览下均可执行且无 CSP 控制台错误。

## 3. 暂存区

- [ ] 加入、列表、缩略图、查看对话框、复制、单删、多选批量删除正常；重启后条目仍在。

## 4. DeepSeek 纯自然语言

- [ ] 填写 API Key 等并保存；未填 Key 时编排说明区强制展开。
- [ ] 已填 Key 时编排区可收起，「自然语言需求」始终可见。
- [ ] 「生成 PlantUML 并填入编辑器」可走通或按预期失败并显示错误/日志。

## 5. 项目目录驱动（2.0 Beta）

- [ ] 「选择项目文件夹…」弹出系统目录对话框，路径显示正确且写入配置（重启后仍保留）。
- [ ] 「刷新目录摘要」生成预览文本，无异常路径崩溃。
- [ ] 「自定义忽略」多行 glob 保存后参与索引；未保存时「一键生成 / 估算」仍使用当前文本框内容。
- [ ] 「估算上下文」不调用 DeepSeek，状态栏给出粗算 tokens 与文件数。
- [ ] 「一键生成：规划选文件 + 源码 +…」在已选目录且已填目标时走「规划 + 制图」；成功则编辑器与预览更新。

## 6. 安装包

- [ ] `release` 中安装包与便携版可安装/运行，关于信息中版本号与当前 `package.json` 一致（如 **2.0.0-beta.2**）。
